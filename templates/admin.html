GitHub authentication

Configure the GitHub App at runtime. The client secret is encrypted with WebSSH's persistent secret and is never returned to the browser.

Set up the GitHub side firstExact GitHub menus, values, permissions, and installation expand_more
  1. Choose the public WebSSH URL. Use HTTPS and form the callback as https://your-webssh-host/auth/github/callback. If WebSSH uses an application-root prefix, place it before /auth/github/callback.
  2. Create a GitHub App. For a personal app, open Profile picture → Settings → Developer settings → GitHub Apps → New GitHub App. For an organization-owned app, open Profile picture → Your organizations → Settings → Developer settings → GitHub Apps → New GitHub App. Organization owners or designated GitHub App managers can create it.
  3. Complete “Basic information”. Give the app a unique name, set Homepage URL to the public WebSSH base URL, and set Callback URL to the exact value used below. Leave Setup URL empty and clear Active under Webhook; WebSSH does not receive webhooks.
  4. Grant the minimum permissions. Keep all repository and account permissions at No access. Only when using Allowed organizations, open Permissions & events → Organization permissions and set Members to Read-only (Members: read).
  5. Create and install the app. Finish with Create GitHub App, then open Install App and install it on the personal account or organization whose resources and membership policy it should use. An organization owner must approve an installation that requests organization permissions.
  6. Copy the two credentials. On the app's General page copy Client ID—not App ID. Under Client secrets, choose Generate a new client secret and copy it immediately. WebSSH does not need an App private key, webhook secret, or PEM file.
  7. Finish here. Paste the Client ID, generated client secret, and identical callback URL below. Add exact organization logins only if the allowlist should be enforced, choose whether to auto-provision non-admin users, enable GitHub sign-in, and save. WebSSH will request administrator reauthentication before accepting the configuration.
