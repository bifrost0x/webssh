# External Go modules allowed in the build list (ADR 0004).
#
# Format: <module> <tier> <importers|-> <reason>
#   tier       A for golang.org/x modules, B for small reviewed libraries.
#              Tier C (own implementations) needs no entry.
#   importers  comma-separated module-relative packages that may import the
#              module directly; a trailing "/" allows a subtree. "-" means
#              the module may only appear as an indirect dependency.
#   reason     why the module is needed and why not the standard library.
#
# Every module linked into a non-test package (go list -deps, all release
# platforms) and every direct requirement in go.mod needs an entry. A new
# entry needs a license check against Apache-2.0 and a maintenance check in
# the pull request that adds it.

Pinned to v0.38.1 (2026-11-26), re-evaluated for writing (M1, F2): v0.38.1 bundles the same engine as v0.38.0 (go-sqlite3-wasm v6.7.35401, SQLite 3.54.1) and fixes the database/sql driver after a transaction SQLite rolled back by itself (INSERT OR ROLLBACK, interrupt, full disk, I/O error): v0.38.0 ran the following statements of the transaction in autocommit mode and stored them (internal/store/abort_test.go fails on v0.38.0); the other changes are Windows blocking locks, Plan 9 support and CI. Writing uses one serialized connection with BEGIN IMMEDIATE, WAL and synchronous = FULL. No known vulnerabilities (vuln.go.dev). v0.x: API breaks possible, single maintainer; updates are reviewed by hand. SQLite CVEs are tracked by hand (ADR 0004).
