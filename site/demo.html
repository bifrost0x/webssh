One minute inside WebSSH

See the workspace in action.

SSH terminals, SFTP files and everyday tools. On infrastructure you control.

The walkthrough, in text

From a shell to the rest of your work.

This video uses the current product interface with prepared example sessions, files and output. The hosts use reserved .example names.

  1. 00:00

    Your servers. Your browser. Your rules.

    WebSSH is introduced as a self-hosted SSH and SFTP workspace. The opening card highlights open source, self-hosting and no built-in telemetry.

  2. 00:04

    One terminal workspace

    An example SSH terminal displays service status. Disk-capacity and current-user commands appear in the terminal, with the connected host identified in the status bar.

  3. 00:12

    Two servers in view

    The operator selects Split pane, assigns the Build Runner session to the second pane and applies the layout. Two terminals now display separate example hosts.

  4. 00:22

    SFTP files side by side

    The File Manager shows two example SFTP sources. The operator selects README.md in the left pane.

  5. 00:28

    Preview and edit a file

    The README preview opens. The operator enters edit mode and adds a release-validation checklist item. The editor displays “Unsaved changes”; this scene demonstrates editing without saving the example file.

  6. 00:38

    Reusable command sets

    The operator opens Baseline diagnostics, a saved command set with System Uptime and Service Status. They search for Disk Usage and add it as the third step.

  7. 00:49

    Keep a note of the next step

    Back in the terminal workspace, the personal notepad stays beside the shell. The operator adds a reminder to verify the deployment.

  8. 00:55

    Bring your own servers

    The final card points to getwebssh.com and the local Docker quickstart. WebSSH is free and open source under the MIT license.
